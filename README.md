### 🚀 Mi Ecosistema de Trabajo

Como desarrollador **Full Stack**, disfruto de la flexibilidad de trabajar en ambos extremos, desde la robustez del backend hasta la interactividad del frontend.

Mis áreas de interés y expertise incluyen:

* **Desarrollo Backend:** Construyendo APIs y servicios escalables con .NET y Node.js.
* **Desarrollo Frontend:** Creando interfaces de usuario dinámicas y responsivas con Angular.
* **Gestión de Datos:** Diseñando y optimizando bases de datos en SQL Server y Oracle.
* **Orquestación y Monitoreo:** Utilizando Docker para desplegar y New Relic para mantener todo bajo control.
